# CV / LinkedIn project description (draft)

**Retail Business Intelligence & Demand Forecasting | Power BI, Python, Scikit-learn**

- Built interactive Power BI reporting for **1,000 retail transaction records across three branches**, covering sales trends, products, customer groups, and payment methods.
- Modelled retail reporting data using **star and snowflake schema prototypes** and designed a proposed BI architecture with staging, validation and warehouse layers.
- Evaluated a **Random Forest one-day-ahead sales forecast** against a previous-week baseline using a chronological holdout; achieved **$1,345.58 vs $1,813.09 MAE** on the 14-day test, while documenting substantial model uncertainty.

**Accuracy note:** The warehouse architecture was proposed, not deployed. Forecast metrics are from an academic dataset and should not be described as production results. Replace or remove the numerical metrics if the repository no longer documents the original analysis.
